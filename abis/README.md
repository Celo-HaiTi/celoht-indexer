# Verified ABIs

These five Hardhat artifacts were generated by compiling `Celo-HaiTi/celoht-smart-contracts` at the verified source checkout used for this deployment. Do not hand-edit them or replace them with interface guesses.

- `CeloHTAgentRegistry.json`
- `CeloHTServicePayments.json`
- `CeloHTEducation.json`
- `CeloHTReforestation.json`
- `CeloHTGovernance.json`

`USDm.json` is intentionally absent until the canonical deployed USDm artifact
is published and verified. The indexer refuses to start without it; it never
uses a mock or hand-authored fallback.

`src/config/abiLoader.ts` accepts the artifact shape and fails closed when a file is missing, invalid, or empty.
